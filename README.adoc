= Showroom Deployer

Helm charts for deploying https://github.com/rhpds/showroom-images[Showroom] on OpenShift.

== Charts

|===
| Chart | Description

| `showroom-single-pod`
| Deploys the Showroom front-end (content, terminal, wetty, proxy, novnc) in a single pod.

| `zerotouch`
| Deploys the Zero Touch showroom variant in a single pod.
|===

== Quick Start

=== Deploy with `helm template` (recommended)

[source,bash]
----
git clone https://github.com/rhpds/showroom-deployer
cd showroom-deployer/charts

helm template showroom ./showroom-single-pod \
  --set deployer.domain=apps.cluster.example.com \
  --set guid=my-guid \
  --set documentation.repoUrl=https://github.com/rhpds/showroom_template_default \
  | oc apply -f -
----

=== Deploy with `helm install`

. Add the Helm repo
+
[source,bash]
----
helm repo add rhpds https://rhpds.github.io/showroom-deployer
helm repo update
----

. Install
+
[source,bash]
----
helm install my-showroom rhpds/showroom-single-pod \
  --set deployer.domain=apps.cluster.example.com \
  --set guid=my-guid \
  --set documentation.repoUrl=https://github.com/rhpds/showroom_template_default
----

=== Private content repositories

Create a Secret in the release namespace holding the git token, then point
`git_cloner.tokenSecret` at it:

[source,bash]
----
oc create secret generic my-git-token \
  --from-literal=GIT_TOKEN=ghp_xxxxxxxxxxxx \
  -n my-showroom-namespace

helm install my-showroom rhpds/showroom-single-pod \
  --set content.repoUrl=https://github.com/myorg/private-content.git \
  --set git_cloner.tokenSecret=my-git-token
----

By default the token is injected into the `git-cloner` init container as a
literal `GIT_TOKEN` env var via `secretKeyRef`. Set `git_cloner.tokenMountMode`
to `file` to instead mount the Secret as a read-only volume and pass
`GIT_TOKEN_FILE` pointing at it, so the token never appears in
`oc get pod -o yaml` / `kubectl describe pod` (requires `git-cloner` v1.2.0+).
Either way, `git-cloner` sends the token as an HTTP auth header scoped to the
repository's origin -- it never appears in the repo URL or in the cloned
repository's git config.

[source,bash]
----
helm install my-showroom rhpds/showroom-single-pod \
  --set content.repoUrl=https://github.com/myorg/private-content.git \
  --set git_cloner.tokenSecret=my-git-token \
  --set git_cloner.tokenMountMode=file
----

|===
| Value | Description | Default

| `git_cloner.tokenSecret`
| Name of an existing Secret holding the token. Empty disables token auth
  entirely -- this is the only way to authenticate `git-cloner`.
| `""`

| `git_cloner.tokenSecretKey`
| Key within that Secret.
| `GIT_TOKEN`

| `git_cloner.tokenMountMode`
| `env` sets the token as a literal env var. `file` mounts the Secret as a
  volume and passes `GIT_TOKEN_FILE` instead, keeping the token out of the
  pod spec.
| `env`

| `git_cloner.tokenUsername`
| Username paired with the token. Empty lets `git-cloner` choose per forge
  (`x-access-token` for GitHub, `oauth2` for GitLab, `x-token-auth` for
  Bitbucket, `token` for Gitea/Forgejo).
| `""`
|===

Authentication failures are not retried, so an invalid or expired token fails
the init container immediately rather than after the full retry budget. Leave
`tokenSecret` unset for public repositories: a malformed credential causes the
forge to reject requests that would otherwise have succeeded anonymously.

== Container Images

All Showroom container images are maintained in https://github.com/rhpds/showroom-images[rhpds/showroom-images] and published to https://quay.io/organization/rhpds[quay.io/rhpds].

== Helm Chart Releases

Charts are released automatically via GitHub Actions when changes are pushed to `charts/` on `main`.
The chart repository is hosted at https://rhpds.github.io/showroom-deployer.
