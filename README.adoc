= Showroom Deployer

Helm charts for deploying https://github.com/rhpds/showroom-images[Showroom] on OpenShift.

== Charts

|===
| Chart | Description

| `showroom-single-pod`
| Deploys the Showroom front-end (content, terminal, wetty, proxy, novnc) in a single pod.

| `zerotouch`
| Deploys the Zero Touch showroom variant in a single pod.
|===

== Quick Start

=== Deploy with `helm template` (recommended)

[source,bash]
----
git clone https://github.com/rhpds/showroom-deployer
cd showroom-deployer/charts

helm template showroom ./showroom-single-pod \
  --set deployer.domain=apps.cluster.example.com \
  --set guid=my-guid \
  --set documentation.repoUrl=https://github.com/rhpds/showroom_template_default \
  | oc apply -f -
----

=== Deploy with `helm install`

. Add the Helm repo
+
[source,bash]
----
helm repo add rhpds https://rhpds.github.io/showroom-deployer
helm repo update
----

. Install
+
[source,bash]
----
helm install my-showroom rhpds/showroom-single-pod \
  --set deployer.domain=apps.cluster.example.com \
  --set guid=my-guid \
  --set documentation.repoUrl=https://github.com/rhpds/showroom_template_default
----

== Container Images

All Showroom container images are maintained in https://github.com/rhpds/showroom-images[rhpds/showroom-images] and published to https://quay.io/organization/rhpds[quay.io/rhpds].

== Helm Chart Releases

Charts are released automatically via GitHub Actions when changes are pushed to `charts/` on `main`.
The chart repository is hosted at https://rhpds.github.io/showroom-deployer.
